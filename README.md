# Práctica de Programación Orientada a Objetos en PHP

En este repositorio se encuentran diferentes ejercicios realizados en PHP sobre Programación Orientada a Objetos.

## Ejercicios realizados

- Uso de clases y métodos estáticos.
- Herencia entre las clases Coche y CocheDeLujo.
- Uso de la palabra reservada `final` para impedir la herencia de una clase.
- Creación de una clase Círculo para calcular el área y el perímetro.
- Implementación de herencia utilizando una clase Persona y las clases Estudiante y Docente.

## Tecnologías utilizadas

- PHP
- WampServer
- Visual Studio Code
